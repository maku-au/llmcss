Quickstart

Install · Component · Layout · Templates · Agents · Pro

CSS library. Classes are plain names like btn and md:flex. Copy CSS, use the CLI, or point an agent at MCP.

1. Link the stylesheet

<link rel="stylesheet" href="https://llmcss.io/llmcss.css" />
<button class="btn btn-primary">Save</button>

Dark mode: data-ai-theme="dark" on <html>. Skin: data-ai-skin="obsidian".

That file is CSS only. Buttons and layout work. Modals, tabs, and data-ai-toggle need the runtime: <script src="https://llmcss.io/llmcss.js" defer></script>. Skip that for a static page.

2. Copy a free component

Open the gallery and copy HTML, or:

npx llmcss list
npx llmcss add btn-variants

Writes components/primitive/btn-variants.html. Agents can fetch https://llmcss.io/r/btn-variants.json.

3. A first layout

<div class="container-w-sm p-8">
  <h1>Hello</h1>
  <p class="text-secondary">Titles use the display face. Body stays the sans.</p>
  <div class="flex gap-2 mt-4">
    <button class="btn btn-primary">Continue</button>
    <button class="btn btn-outline">Cancel</button>
  </div>
</div>

No nested cards, no pulsing static dots, no purple gradients. Agent rules: AGENTS.md.

4. Templates

npx llmcss templates
npx llmcss template get wireframe-nav-minimal
npx llmcss template blueprint saas-landing

Template gallery

5. Agents

npx llmcss-mcp

Stdio MCP. It talks to llmcss.io. Nothing to host yourself.

6. Pro

$9/month Polar subscription for themed templates and kits. Every component is MIT. Token is shown once on /account.

npx llmcss login <token>
npx llmcss template get themed-obsidian-status-rail
