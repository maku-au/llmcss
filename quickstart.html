Quickstart

CSS library. Classes are ai-*. Copy CSS, use the CLI, or point an agent at MCP.

1. Link the stylesheet

<link rel="stylesheet" href="https://llmcss.io/llmcss.css" />
<button class="ai-btn ai-btn-primary">Save</button>

Dark mode: data-ai-theme="dark" on <html>. Skin: data-ai-skin="obsidian".

2. Copy a free component

Open the gallery and copy HTML, or:

npx llmcss list
npx llmcss add btn-variants

Writes components/primitive/btn-variants.html. Agents can fetch https://llmcss.io/r/btn-variants.json.

3. A first layout

<div class="ai-container" style="max-width: 40rem; padding: var(--ai-space-8);">
  <h1>Hello</h1>
  <p class="ai-text-secondary">Titles use the display face. Body stays the sans.</p>
  <div class="ai-flex ai-gap-2" style="margin-top: var(--ai-space-4);">
    <button class="ai-btn ai-btn-primary">Continue</button>
    <button class="ai-btn ai-btn-outline">Cancel</button>
  </div>
</div>

No nested cards, no pulsing static dots, no purple gradients. Agent rules: AGENTS.md.

4. Templates

npx llmcss templates
npx llmcss template get wireframe-nav-minimal
npx llmcss template blueprint saas-landing

Template gallery

5. Agents

npx llmcss-mcp

Stdio MCP. It talks to llmcss.io. Nothing to host yourself.
